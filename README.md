# 🐍 Snake Game

A classic Snake game built with Python and the `turtle` graphics library.  
The player controls the snake to eat food, grow longer, and avoid collisions with walls or itself.

---

## 🎮 Features
- Snake movement with arrow keys
- Food spawning at random positions
- Score tracking
- Game over detection (wall and tail collision)
